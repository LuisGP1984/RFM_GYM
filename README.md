# RFM GYM

App web para apuntar kg y repeticiones de una rutina de 4 días con histórico por ejercicio y exportación a Excel.

**Abrir la app:** https://TU-USUARIO.github.io/sobrecarga/

- Los datos se guardan en el navegador de cada dispositivo (no se envían a ningún servidor).
- Menú › Guardar copia de seguridad: descarga un `.json` para no perder los datos o pasarlos a otro móvil.
- Menú › Exportar a Excel: hoja "Tabla" (formato del Excel original) y hoja "Datos".
- En el móvil: Chrome › ⋮ › Añadir a pantalla de inicio. Funciona sin conexión.
